# WMP Madrid input archive

Input-only research store for LEMD / Late Live 16:00 Europe/Madrid. Source objects, attempts, checkpoints and gaps are append-only; journal.json is a derived index. No probabilities, trades, automatic promotion or OOS forecast claims. Workflow activation is controlled by the main branch; creating this data branch starts no job.

Code and operating contract: research/wmp_madrid_shadow_v1/ARCHIVE.md on the code branch. Weather data attribution: Open-Meteo (CC BY 4.0), NOAA/NCEP, ECMWF, DWD, ECCC; METAR: NOAA Aviation Weather Center. Payloads are normalized and timestamped; no station-offset or spread tuning.
